# 🗺️ Markdown Editor Blueprint (Phase 9 - Refinamiento UX)

## 🛠️ Stack Tecnológico
- **Lenguaje:** C++20 | **Framework:** Qt 6.10.1 (MSVC 2022)
- **Compilación:** CMake | **Gestor:** vcpkg

## 🏗️ Arquitectura de Clases
1. **MainWindow:** 
   - **Theming Engine**: 6 paletas completas (Tokyo Night, Nord, Catppuccin, Gruvbox, One Dark, Light).
   - **Buffer Dual**: `m_rawMarkdownBuffer` es la fuente de verdad.
   - **Shortcut**: `Ctrl+E` conmuta entre Edit y Preview.
2. **SearchWorker:** Búsqueda híbrida asíncrona (Título primero, luego contenido).
3. **MarkdownTextEdit:** Gestión de Zoom, Wiki-links y cursor dinámico.
