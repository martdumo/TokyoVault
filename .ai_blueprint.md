🗺️ Markdown Editor Blueprint: Proyecto "Maletín"
1. 🛠️ Stack Tecnológico y Entorno
Lenguaje: C++20.
Framework: Qt 6.10.1 (MSVC 2022, 64-bit).
Sistema de Compilación: CMake 3.20+.
Gestor de Paquetes: vcpkg (Integrado en F:/vcpkg).
Directorio Raíz: F:/Proyectos/MarkdownEditor.
Estructura de Carpetas:
/src: Archivos de implementación (.cpp).
/include: Archivos de cabecera (.h).
/assets: Recursos externos (fuentes, iconos).
/build o /out: Directorios de compilación (ignorados en Git).
2. 🏗️ Arquitectura de Clases
A. MainWindow (Orquestador)
Es el núcleo de la aplicación. Gestiona la ventana principal, menús y la lógica de negocio. Delega la lógica de estilo y parseo a EditorStyler.
B. EditorStyler (Motor de Estilo y Parseo)
Clase extraída de MainWindow para manejar la conversión de Markdown a HTML. Esto reduce drásticamente el tamaño de MainWindow y mejora la modularidad.
C. MarkdownTextEdit (Motor de Edición)
Subclase de QTextEdit con eventos de Zoom y Mouse para Wiki-links y menú contextual estándar.
D. MarkdownHighlighter (Resaltador)
Subclase de QSyntaxHighlighter con colores hardcodeados del tema Tokyo Night.
E. FindReplaceDialog (Búsqueda y Reemplazo)
Diálogo no modal para buscar y reemplazar texto en el editor activo.
F. SearchWorker & SearchThread (Búsqueda en Vault)
Buscador asíncrono en hilo secundario con lógica híbrida (Título + Contenido).
3. 🎨 Convenciones de UI y UX
Preview Logic: El modo lectura es una proyección HTML generada por `EditorStyler` para asegurar paridad visual y estética 1:1.
Renderizado Seguro (Anti-Colisión): El parser en `EditorStyler` genera HTML limpio (solo con back-references `\1`), y los placeholders de estilo se aplican de forma segura en la plantilla principal de CSS, evitando corrupción del texto del usuario.
Persistencia: Se usa QSettings para recordar: última carpeta, fuente, tema y estado de la ventana.
4. 🔒 Seguridad de Archivos (File Guard)
Se implementó una capa de seguridad que impide la apertura de archivos mayores a 5MB. En la función `loadFile`, se verifica el tamaño del archivo usando `QFileInfo(filePath).size()`, y si supera el límite de 5MB, se muestra un mensaje de advertencia y se cancela la operación.
5. 🎨 Tema Hardcodeado (Tokyo Night)
Se eliminó la estructura modular de temas y se hardcodeó el tema Tokyo Night en toda la aplicación:
- Colores principales: Ventana #1a1b26, Editor/Listas #16161e, Texto #c0caf5, Acento #7aa2f7
- Colores del resaltador: Títulos #bb9af7, Links #7aa2f7, Código #9ece6a, Negrita #ff9e64
- El CSS se aplica directamente en el constructor de MainWindow con `qApp->setStyleSheet(styleSheet)`
6. 📌 Estado de Implementación (Fase 25 - Simplificación y Seguridad)
✅ Finalizado y Estable:
- Seguridad de Archivos (File Guard): Se implementó en la función `loadFile(const QString& filePath, ...)` en `src/MainWindow.cpp`. Antes de abrir el archivo, se verifica su tamaño con `QFileInfo(filePath).size()`. Si el tamaño es mayor a 5 * 1024 * 1024 bytes (5MB), se muestra un `QMessageBox::warning` que dice 'Archivo demasiado grande por seguridad (Límite 5MB)' y se retorna `false`.
- Hardcoding Tokyo Night: Se borraron las variables `m_themes`, `m_currentThemeName` y el slot `applyTheme` de `MainWindow`. Se definió el QSS directamente en el constructor de `MainWindow` con los colores fijos: Ventana #1a1b26, Editor/Listas #16161e, Texto #c0caf5, Acento #7aa2f7. Se aplica con `qApp->setStyleSheet(styleSheet);`.
- Sincronización MarkdownHighlighter: Se quitó la dependencia de la estructura Theme. Se hardcodearon los colores en el constructor: Títulos #bb9af7, Links #7aa2f7, Código #9ece6a, Negrita #ff9e64.
- Simplificación del Proyecto: Se eliminó la funcionalidad de cambio de temas manteniendo solo el tema Tokyo Night como tema único de la aplicación.
