# 🗺️ Markdown Editor Blueprint (Phase 9: High-Efficiency)

## 🏗️ Nivel 1: Arquitectura y Reglas Globales
- **Stack:** C++20 / Qt 6.10.1 / CMake / vcpkg.
- **Buffer Dual:** `m_rawMarkdownBuffer` es la "fuente de la verdad". Se carga en `loadFile` y se usa para restaurar el texto al salir de Preview.
- **Memoria:** Gestión jerárquica de Qt (Parents/Children).
- **Regex:** Siempre usar `R"(...)` (Raw String Literals).
- **Seguridad:** Navegar requiere `maybeSave()` → Retorna `true` solo si es seguro proceder.

## 📦 Nivel 2: Módulos Técnicos
### M1: Renderizado (MainWindow::toggleEditMode)
- **Transformación:** Markdown → Preview. 
- **Fix Líneas:** Reemplazo de `\n\n` por `\n&nbsp;\n` para evitar colapso de párrafos.
- **Wiki-links:** `[[Nota]]` → `<a href="Nota.md">Nota</a>`.

### M2: Búsqueda (SearchWorker & QThread)
- **Lógica:** Híbrida (Título → Contenido).
- **Control:** Debounce via `QTimer` (800ms) en la barra de búsqueda.

### M3: Navegación (handleLinkNavigation)
- **Flujo:** Externa (URL) → Interna (Archivo).
- **Seguridad:** Si el archivo no existe, pregunta "Crear?" → Si "Yes" → `maybeSave()` → Crear y Cargar.
