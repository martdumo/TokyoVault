🗺️ Markdown Editor Blueprint: Proyecto "Maletín"
1. 🛠️ Stack Tecnológico y Entorno
Lenguaje: C++20.
Framework: Qt 6.10.1 (MSVC 2022, 64-bit).
Sistema de Compilación: CMake 3.20+.
Gestor de Paquetes: vcpkg (Integrado en F:/vcpkg).
Directorio Raíz: F:/Proyectos/MarkdownEditor.
Estructura de Carpetas:
/src: Archivos de implementación (.cpp).
/include: Archivos de cabecera (.h).
/assets: Recursos externos (fuentes, iconos).
/build o /out: Directorios de compilación (ignorados en Git).
2. 🏗️ Arquitectura de Clases
A. MainWindow (Orquestador)
Es el núcleo de la aplicación. Gestiona la ventana principal, menús y la lógica de negocio. Delega la lógica de estilo y parseo a EditorStyler.
B. EditorStyler (Motor de Estilo y Parseo)
Clase extraída de MainWindow para manejar toda la lógica de temas (setupThemes, applyTheme) y la conversión de Markdown a HTML. Esto reduce drásticamente el tamaño de MainWindow y mejora la modularidad.
C. MarkdownTextEdit (Motor de Edición)
Subclase de QTextEdit con eventos de Zoom y Mouse para Wiki-links y menú contextual estándar.
D. MarkdownHighlighter (Resaltador)
Subclase de QSyntaxHighlighter con soporte para temas.
E. FindReplaceDialog (Búsqueda y Reemplazo)
Diálogo no modal para buscar y reemplazar texto en el editor activo.
F. SearchWorker & SearchThread (Búsqueda en Vault)
Buscador asíncrono en hilo secundario con lógica híbrida (Título + Contenido).
3. 🎨 Convenciones de UI y UX
Preview Logic: El modo lectura es una proyección HTML generada por `EditorStyler` para asegurar paridad visual y estética 1:1.
Renderizado Seguro (Anti-Colisión): El parser en `EditorStyler` genera HTML limpio (solo con back-references `\1`), y los placeholders de estilo se aplican de forma segura en la plantilla principal de CSS, evitando corrupción del texto del usuario.
Persistencia: Se usa QSettings para recordar: última carpeta, fuente, tema y estado de la ventana.
