# 🗺️ Markdown Editor Blueprint (Phase 7)

## 📝 Change Log
*   **Phase 7: Estabilización de Regresiones**: Se han corregido crashes críticos y errores de lógica. Se ha estabilizado el renderizado del modo preview, la funcionalidad de búsqueda y la creación de nuevos archivos.
*   **Phase 6: Robustez y Usabilidad**: Se introdujo un 'debounce' timer para la búsqueda, se añadió la función "Nuevo Archivo", y se unificó la lógica de creación de archivos desde links.
*   **Phase 5: Búsqueda por Contenido y Estabilización**: Se implementó la búsqueda de contenido global y asíncrona, y se aplicaron arreglos a los márgenes y la compilación.

## 🛠️ Stack Tecnológico
- **Lenguaje:** C++20
- **Framework:** Qt 6.10.1 (MSVC 2022)
- **Sistema de Compilación:** CMake

## 🏗️ Arquitectura de Clases
1.  **`MainWindow`:** Núcleo de la aplicación.
    *   **Búsqueda Optimizada**: Usa un `QTimer` para aplicar 'debounce' a la búsqueda por contenido, mejorando el rendimiento.
    *   **Gestión de Archivos**: Incluye la funcionalidad `newFile()` para crear nuevas notas, ahora con una llamada a `QInputDialog` a prueba de crashes.
    *   **Renderizado de Preview Estable**: Se revirtió a `setMarkdown()` para el modo preview, con el estilo de los links gestionado globalmente vía QSS, solucionando errores de formato.
    *   **Sistema de Buffer Dual**: Previene la corrupción de datos al cambiar entre modo edición y preview.
2.  **`SearchWorker`:**
    *   Corre en un `QThread` para no bloquear la UI durante búsquedas de contenido.
3.  **`MarkdownTextEdit`:**
    *   Provee el cursor dinámico y emite señales de activación de links.
