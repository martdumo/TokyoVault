# 🗺️ Markdown Editor Blueprint (Phase 2 Recovery)

## 📝 Change Log
*   **Emergency Recovery**: This version was built via total file rewrite (`write_file`) to recover from a catastrophic truncation failure during the previous attempt. All Phase 2 features were successfully implemented during this reconstruction.

## 🛠️ Stack Tecnológico
- **Lenguaje:** C++20
- **Framework:** Qt 6.10.1 (MSVC 2022)
- **Gestor de Paquetes:** vcpkg (Integrado en F:/vcpkg)
- **Sistema de Compilación:** CMake

## 🏗️ Arquitectura de Clases
1.  **`MainWindow`:** Ventana principal y núcleo de la aplicación.
    *   Gestiona menús, toolbars, y barra de estado.
    *   Controla la lógica de Vaults (carpetas) con `QFileSystemModel`.
    *   **Motor de Temas (`Theming Engine`)**:
        *   Define una `QMap<QString, Theme>` para almacenar múltiples paletas de colores.
        *   Contiene la función `applyTheme(const QString& themeName)` que genera una hoja de estilos (QSS) dinámica para toda la aplicación.
        *   Puebla un submenú "Temas" para la selección del usuario.
        *   Comunica el cambio de tema al `MarkdownHighlighter`.
2.  **`MarkdownTextEdit` (Subclase de `QTextEdit`):**
    *   Maneja el zoom con `wheelEvent` (Ctrl + Rueda) y atajos de teclado (Ctrl+/Ctrl-).
    *   Detecta Wiki-Links (`[[...]]`) con `mousePressEvent` (Ctrl+Click) y emite `wikiLinkActivated(QString)`.
3.  **`MarkdownHighlighter` (Subclase de `QSyntaxHighlighter`):**
    *   **Refactorizado para Temas:** Ya no usa colores hardcodeados.
    *   Expone un método público `setTheme(const Theme& theme)` que actualiza los colores de todos los formatos de texto.
    *   Llama a `rehighlight()` para aplicar los nuevos colores de forma inmediata.
    *   Sigue usando `Raw String Literals` (`R"(...)"`) para las expresiones regulares.
4.  **`FindReplaceDialog`:** Diálogo no modal para búsqueda y reemplazo.
5.  **`Theme` (struct):**
    *   Estructura de datos simple definida en `MainWindow.h`.
    *   Almacena los `QColor` para la UI (`windowBg`, `editorBg`, `textFg`, etc.) y para el resaltador (`heading`, `link`, `code`, etc.).

## 🎨 Sistema de Temas y Estética
*   **Implementación Dinámica:** Se abandonó el archivo `style.qss` estático. `MainWindow` ahora genera el QSS en tiempo de ejecución basado en el tema activo.
*   **Temas Disponibles:**
    1.  Tokyo Night (Por defecto)
    2.  Nord
    3.  Catppuccin
    4.  Gruvbox
    5.  One Dark
    6.  Light Mode

## ⚙️ Reglas y Convenciones para la IA
*   **Regex:** Usar siempre Raw String Literals: `QRegularExpression(R"(\[\[.+\]\])")`.
*   **Memoria:** Preferir la jerarquía de padres/hijos de Qt o `std::unique_ptr`.
*   **Archivos:** Mantener headers en `include/` y fuentes en `src/`.
*   **Persistencia Total:** Usar `QSettings` para guardar:
    *   `lastVaultPath`: Última carpeta abierta.
    *   `startup_file`: Archivo a abrir al inicio.
    *   `font`: Fuente y tamaño del editor.
    *   `theme`: Nombre del tema activo.
    *   `geometry` y `windowState` de la ventana principal.
