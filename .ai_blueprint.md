🗺️ Markdown Editor Blueprint: Proyecto "Maletín"
1. 🛠️ Stack Tecnológico y Entorno
Lenguaje: C++20.
Framework: Qt 6.10.1 (MSVC 2022, 64-bit).
Sistema de Compilación: CMake 3.20+.
Gestor de Paquetes: vcpkg (Integrado en F:/vcpkg).
Directorio Raíz: F:/Proyectos/MarkdownEditor.
Estructura de Carpetas:
/src: Archivos de implementación (.cpp).
/include: Archivos de cabecera (.h).
/assets: Recursos externos (fuentes, iconos).
/build o /out: Directorios de compilación (ignorados en Git).
2. 🏗️ Arquitectura de Clases
A. MainWindow (Orquestador)
Es el núcleo de la aplicación. Gestiona la ventana principal, menús y la lógica de negocio.
Manejo de Vault: Usa QFileSystemModel + QSortFilterProxyModel para navegar por carpetas y archivos .md.
Sistema de Buffer Dual: Mantiene m_rawMarkdownBuffer como la "única fuente de la verdad" del texto Markdown.
Navegación Segura: Implementa maybeSave() que se dispara antes de cargar una nueva nota o crear un archivo.
Motor de Temas: Múltiples temas dinámicos.
B. MarkdownTextEdit (Motor de Edición)
Subclase de QTextEdit con eventos de Zoom y Mouse para Wiki-links.
C. MarkdownHighlighter (Resaltador)
Subclase de QSyntaxHighlighter con soporte para temas.
D. FindReplaceDialog (Búsqueda y Reemplazo)
Diálogo no modal para buscar y reemplazar texto en el editor activo.
E. SearchWorker & SearchThread (Búsqueda en Vault)
Buscador asíncrono en hilo secundario con lógica híbrida (Título + Contenido).
3. 🎨 Convenciones de UI y UX
Filtro de Vault: El buscador mantiene el rootIndex en la carpeta del Vault activo.
Preview Logic: El modo lectura es una proyección HTML generada manualmente. Se abandona setMarkdown() y se usa un parser manual (Regex) + setHtml() para asegurar paridad visual 1:1, con estilos CSS inyectados (`white-space: pre-wrap`) para preservar todo el whitespace.
Persistencia: Se usa QSettings para recordar: última carpeta, fuente, tema y estado de la ventana.
4. 📌 Estado de Implementación (Fase 16.0)
✅ Finalizado y Estable:
Estabilidad Crítica: ¡SOLUCIONADO! Corregido un crash de Access Violation (0xC0000005) en el menú contextual del TreeView. La causa era el uso de un QModelIndex del proxy model directamente en el source model. Se implementó el mapeo correcto con `QSortFilterProxyModel::mapToSource`.
Paridad Visual Completa (Líneas y Espacios): ¡SOLUCIONADO! La regresión que colapsaba líneas vacías consecutivas en el modo Preview ha sido reparada. Se inyecta el estilo CSS `white-space: pre-wrap` en el body del HTML generado, garantizando que el espaciado vertical del editor se respete 1:1 en la vista previa.
Funcionalidad de Buscar y Reemplazar: ¡IMPLEMENTADO! Se ha añadido un diálogo funcional de "Buscar y Reemplazar" (Ctrl+F) que permite buscar siguiente, reemplazar, y reemplazar todo, con opciones de sensibilidad a mayúsculas y palabras completas.
Portabilidad de Build (Linux): ¡IMPLEMENTADO! El archivo `CMakeLists.txt` ahora es portable. Las rutas específicas de Windows para vcpkg y Qt están encapsuladas en un bloque `if(WIN32)`, permitiendo que en otros sistemas (como Arch Linux) `find_package` busque las dependencias de forma estándar.
Parser de Markdown Básico: El parser manual soporta los elementos más comunes (headers, listas, negrita, cursiva, código, etc.).
Funcionalidades Avanzadas de Vault: Soporte para búsqueda de archivos, creación de carpetas, renombrado con actualización de vínculos, etc.
Sistema de Temas y persistencia de fuentes.
Búsqueda híbrida (Título + Contenido) en segundo plano.
