# 🗺️ Markdown Editor Blueprint (Tokyo Terminal Edition)

## 🛠️ Stack Tecnológico
- **Lenguaje:** C++20
- **Framework:** Qt 6.10.1 (MSVC 2022)
- **Gestor de Paquetes:** vcpkg (Integrado en F:/vcpkg)
- **Sistema de Compilación:** CMake

## 🏗️ Arquitectura de Clases
1. **MainWindow:** Ventana principal. Maneja menús, barra de estado, navegación de historial (QList + index) y lógica de Vault (QFileSystemModel + QSortFilterProxyModel).
2. **MarkdownTextEdit (Subclase de QTextEdit):** 
   - Maneja Zoom (Ctrl + Rueda / Ctrl +/-).
   - Detecta Wiki-Links `[[ ]]` mediante `mousePressEvent` + Ctrl+Click.
   - Emite señal `wikiLinkActivated(QString)`.
3. **MarkdownHighlighter (Subclase de QSyntaxHighlighter):**
   - Resalta Títulos (Cyan), Links (Púrpura) y Código (Naranja).
   - Usa **Raw String Literals** `R"(...)"` para evitar errores de escape.
4. **FindReplaceDialog:** Diálogo no modal para búsqueda y reemplazo de texto.

## 🎨 Estética (Tokyo Night Palette)
- **Background:** `#1a1b26` (Principal), `#24283b` (Editor/Listas)
- **Foreground:** `#a9b1d6`
- **Accents:** `#7aa2f7` (Azul), `#bb9af7` (Púrpura), `#7dcfff` (Cyan)

## ⚙️ Reglas y Convenciones para la IA
- **Regex:** Usar siempre Raw String Literals: `QRegularExpression(R"(\[\[.+\]\])")`.
- **Memoria:** Preferir la jerarquía de padres/hijos de Qt o `std::unique_ptr`.
- **Archivos:** Mantener headers en `include/` y fuentes en `src/`.
- **Persistencia:** Usar `QSettings` para guardar `lastVaultPath`, `startup_file` y fuentes.
