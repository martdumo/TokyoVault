## 📌 Hitos Alcanzados (Sesión Actual - Estabilización y Features)

### 1. ¡SOLUCIONADO! Crash Crítico en Menú Contextual del Vault (Arquitectura v6.1)

Se ha reparado un fallo crítico que causaba una violación de acceso (`0xC0000005`) al hacer clic derecho en el `QTreeView` del Vault.

- **Diagnóstico Final:**
    - **Causa Raíz:** La función `onTreeContextMenu` obtenía un `QModelIndex` del `QTreeView` (que opera sobre el `QSortFilterProxyModel`) y lo utilizaba directamente para consultar el `QFileSystemModel` (el source model). Esta incoherencia de índices provocaba el crash cuando el modelo estaba filtrado o reordenado.
- **Solución Definitiva Implementada:**
  1.  **Mapeo Correcto de Índices:** En `onTreeContextMenu` y funciones relacionadas (`setDefaultFile`, `showRenameDialog`, `deleteFileOrFolder`), se ha implementado la lógica correcta:
      a. Se obtiene el `proxyIndex` desde el `QTreeView`.
      b. Se valida que el `proxyIndex` sea válido.
      c. Se mapea al `sourceIndex` usando `m_proxyModel->mapToSource(proxyIndex)`.
      d. Se valida que el `sourceIndex` resultante sea válido antes de pasarlo al `m_fileSystemModel`.
- **Beneficio:** La aplicación es ahora estable. El menú contextual del explorador de archivos funciona de manera fiable en todas las condiciones (con y sin filtros de búsqueda).

### 2. ¡SOLUCIONADO! Regresión Visual de Líneas Vacías en Modo Preview (Arquitectura v6.2)

Se ha corregido un bug visual donde el modo Preview colapsaba múltiples saltos de línea consecutivos, rompiendo la paridad vertical 1:1 con el editor.

- **Diagnóstico Final:**
    - **Causa Raíz:** El renderizador HTML de Qt, por defecto, colapsa los espacios en blanco y saltos de línea, similar a un navegador web. La conversión manual de `\n` a `<br>` era insuficiente y propensa a errores.
- **Solución Definitiva Implementada:**
  1.  **Inyección de CSS Estratégico:** En `toggleEditMode`, se ha modificado la hoja de estilos inyectada en el HTML generado:
      a.  Se añadió la propiedad `white-space: pre-wrap;` al estilo del `<body>`. Esto instruye al renderizador para que preserve todas las secuencias de espacios y saltos de línea, pero permitiendo el ajuste de línea (word wrap).
      b.  Se eliminó la frágil sustitución manual de `\n` por `<br>`.
- **Beneficio:** La paridad visual entre el modo edición y el modo preview es ahora del 100% en lo que respecta al espaciado vertical, tal como lo exige la arquitectura del proyecto.

### 3. ¡IMPLEMENTADO! Funcionalidad Completa de "Buscar y Reemplazar" (Arquitectura v6.3)

Se ha implementado desde cero la funcionalidad de buscar y reemplazar texto, una característica clave del roadmap.

- **Solución Definitiva Implementada:**
  1.  **Integración de Diálogo:** Se ha conectado el `FindReplaceDialog` a la `MainWindow`. La ventana se instancia de forma no modal, permitiendo la interacción continua con el editor.
  2.  **Implementación de Lógica:** Se han completado las funciones `findNextInEditor`, `replaceInEditor` y `replaceAllInEditor` en `MainWindow`:
      - Usan `QTextEdit::find()` para la búsqueda, respetando las flags (sensibilidad a mayúsculas/minúsculas, palabras completas) configuradas en el diálogo.
      - `replaceAllInEditor` itera de forma segura por todo el documento, reemplazando todas las coincidencias.
      - Se provee feedback al usuario mediante `QMessageBox` al finalizar la búsqueda o el reemplazo.
- **Beneficio:** El editor ahora cuenta con una herramienta de edición esencial, aumentando significativamente su utilidad.

### 4. ¡IMPLEMENTADO! Portabilidad de Build para Linux (Arquitectura v6.4)

Se ha modificado el sistema de compilación para que el proyecto pueda ser compilado en sistemas no Windows, como Arch Linux.

- **Diagnóstico Final:**
    - **Causa Raíz:** El archivo `CMakeLists.txt` contenía rutas absolutas y configuraciones (`CMAKE_TOOLCHAIN_FILE`, `CMAKE_PREFIX_PATH`) específicas para un entorno de desarrollo Windows.
- **Solución Definitiva Implementada:**
  1.  **Lógica Condicional en CMake:** Se ha encapsulado toda la configuración específica de Windows dentro de un bloque `if(WIN32) ... else() ... endif()`.
  2.  **Búsqueda Estándar:** La rama `else` deja que `find_package(Qt6 ...)` opere de la manera estándar en sistemas POSIX, buscando Qt en las rutas de instalación del sistema.
- **Beneficio:** El proyecto ya no está atado a una sola plataforma o configuración de desarrollador, facilitando la colaboración y el deployment en Linux.
