# AI Session Handoff: Markdown Editor Project

## 🏗️ Estado Técnico Actual
- **Stack:** C++20, Qt 6.10.1 (MSVC 2022), CMake, vcpkg.
- **Arquitectura Clave:**
  - **Buffer Dual:** `m_rawMarkdownBuffer` como fuente de la verdad.
  - **Renderizado Preview:** Se abandona por completo el motor `setMarkdown()` de Qt. Se ha implementado un **parser manual de Markdown a HTML** usando Expresiones Regulares para tener control absoluto sobre el renderizado y garantizar la paridad visual.

## 📌 Hitos Alcanzados (Sesión Actual)

### 1. ¡SOLUCIONADO! El Bloqueador Crítico: Colapso de Líneas Vacías (Arquitectura v5.0)

Tras múltiples intentos fallidos, se implementó una solución radical que resuelve el problema de forma definitiva.

- **Diagnóstico Final:** El parser CommonMark (MD4C) de Qt es, por diseño, la causa del colapso de líneas. Ningún pre-procesamiento de texto o post-procesamiento de HTML con `setMarkdown()` es fiable.
- **Solución Definitiva Implementada:**
  1.  **Se abandona `setMarkdown()` para la visualización:** Se ha creado una nueva lógica en `toggleEditMode`.
  2.  **Parser Manual a HTML:**
      a.  Se escapa el texto plano para evitar que el HTML se corrompa.
      b.  Se aplican reemplazos con Expresiones Regulares para convertir la sintaxis básica de Markdown (`**bold**`, `*italic*`, `` `code` ``, `[[wiki-links]]`) a sus etiquetas HTML equivalentes (`<b>`, `<i>`, `<code>`, `<a href=...`).
      c.  **La clave de la solución:** Cada carácter de nueva línea (`\n`) se reemplaza directamente por una etiqueta `<br>`.
      d.  El string HTML resultante se envuelve en una estructura `<html><body>...</body></html>` y se renderiza con `setHtml()`.
- **Beneficio:** Esta arquitectura garantiza una **paridad visual 1:1** del 100% entre el editor y la vista previa, incluyendo saltos de línea, líneas vacías y espacios, que era la máxima prioridad.
- **Trade-off:** El parser manual actual es básico y no soporta sintaxis compleja (listas, tablas, etc.), lo cual se ha documentado en el `ai_blueprint.md` como un punto a mejorar en el futuro.
